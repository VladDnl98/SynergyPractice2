# Финансовый кабинет

Простое full-stack веб-приложение для учёта личных доходов и расходов студента с автоматической аналитикой.

## Технологии

- Backend: Python + Flask
- База данных: SQLite (`database.db`)
- Frontend: HTML + Bootstrap 5 + Chart.js

## Функционал

- Регистрация, вход и выход пользователя
- Хэширование паролей (`werkzeug.security`)
- Сессии Flask
- Дашборд с балансом и итогами
- Добавление и удаление транзакций (доход/расход)
- Категории в виде выпадающего списка (по типу транзакции)
- Аналитика:
  - круговая диаграмма расходов по категориям за текущий месяц
  - график доходов/расходов по месяцам
  - итоги за месяц и за всё время
- Адаптивный интерфейс в цветовой схеме белый/красный/чёрный

## Запуск проекта

1. Создайте виртуальное окружение:
   ```bash
   python3 -m venv .venv
   ```
2. Установите зависимости:
   ```bash
   .venv/bin/pip install -r requirements.txt
   ```
3. Запустите приложение:
   ```bash
   .venv/bin/python app.py
   ```
4. Откройте в браузере:
   [http://127.0.0.1:5050](http://127.0.0.1:5050)

При необходимости можно указать свой порт:
```bash
PORT=5001 .venv/bin/python app.py
```

При первом запуске база `database.db` создаётся автоматически.
